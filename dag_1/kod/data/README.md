- Dataset: AI4I 2020 Predictive Maintenance
- Källa: UCI Machine Learning Repository
- Sida: https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset
- DOI: https://doi.org/10.24432/C5HS5C
- Licens: Creative Commons Attribution 4.0 International, CC BY 4.0
- Hämtad: 2026-10-12

Filen kan hämtas på nytt med:

```bash
source .venv/bin/activate
python dag_1/kod/python/download_data.py
```
